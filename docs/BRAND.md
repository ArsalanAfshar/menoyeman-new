# Brand — MenoyeMan (منوی من)

## Source of truth

The owner's original logo file (`لوگو منوی من.svg`) is the single source of truth.
Rules:

- **Never** redraw, recolor, stretch, rotate, or add effects to the logo.
- Keep the untouched original in `resources/brand/original/` for reference.
- The sanitized, inlined copy used by views lives at `resources/brand/logo.svg`.
- Icon/OG/favicon variants are **generated** from it by `php scripts/build-brand-assets.php`
  (never edited by hand).

## Palette

The brand orange is **sampled from the owner's logo**: `#F15A22`. It wins over any earlier
suggestion of the palette. Because white text on `#F15A22` fails WCAG AA (3.37:1), the token
scale provides darker stops for buttons and text.

| Token | Value | Typical use |
|---|---|---|
| `brand-50` | `#FFF7F0` | page tints, hovered rows |
| `brand-100` | `#FFEEDC` | chips, soft surfaces |
| `brand-200` | `#FDD9B4` | borders, chips |
| `brand-300` | `#F9B27B` | dark-mode accents, illustrations |
| `brand-400` | `#F58443` | dark-mode buttons (dark text) |
| **`brand-500`** | **`#F15A22`** | **logo orange — decorative / large text only** |
| `brand-600` | `#CC4210` | primary buttons, badges (white text) |
| `brand-700` | `#B2370E` | links, hover/pressed, light-mode text |
| `brand-800` | `#8E2D0F` | dark-mode buttons, deep accents |
| `brand-900` | `#6E240C` | darkest accent, gradients |

Neutrals use the `ink` scale (`ink-900 #1C1917` … `ink-500 #78716C`).
**Destructive actions are red, never orange** (`danger-600 #B91C1C`), so "delete" cannot be
confused with a brand action. Success `#15803D`, warning `#EAB308`.

Utility classes and CSS custom properties are generated from these tokens in
`resources/css/app.css`; Tailwind is configured to expose them as `bg-brand-600`, `text-brand-700`, ….

**All pairs pass.** Practical rules that follow from this table:

- Primary buttons: `bg-brand-600` + white text (never `bg-brand-500` with white text).
- `brand-500` is for the logo, icons, borders, and *large* text only.
- In dark mode, use `brand-400` surfaces with `ink-900` text, or `brand-800` with white text.

## Typography

**Vazirmatn** (variable) is self-hosted at `resources/fonts/Vazirmatn-Variable.woff2` and declared
with `@font-face` in `resources/css/app.css` — no Google Fonts. Persian digits (۰۱۲۳۴۵۶۷۸۹) are
produced by `App\Support\Persian::digits()`; Latin digits never reach the UI.

## Assets generated by `scripts/build-brand-assets.php`

| Output | Purpose |
|---|---|
| `resources/brand/logo.svg` | sanitized inline logo (view partial) |
| `public/brand/logo.svg` | direct-link logo |
| `public/favicon.ico`, `public/favicon.svg` | browser favicons |
| `public/apple-touch-icon.png` | iOS home-screen icon |
| `public/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | PWA manifest icons |
| `public/og-image.png` | Open Graph / social preview |
| `resources/brand/og-image.png` | source copy of the OG image |

Regenerate after changing the logo, then commit the outputs.

## Voice and naming

- Product name in Persian UI: **منوی من**; latin: *MenoyeMan*; domain **MenoyeMan.ir**.
- Persian numbers, Jalali dates, Toman amounts, right-to-left layouts everywhere.
- Friendly, plain language — no technical jargon, no English words in the interface.
